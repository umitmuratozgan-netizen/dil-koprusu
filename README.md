# Dil Köprüsü

Türkiye'den Belçika'ya (Flanders) taşınanlar için Felemenkçe öğrenme, sesli tercüman ve yeni hayat yardımcısı. Telefonda "Ana ekrana ekle" ile uygulama gibi çalışır.

**Aç:** https://umitmuratozgan-netizen.github.io/dil-koprusu/

- **Öğren:** A1 → B1 seviye yolu, günlük ders, kartlar, dikte, kelime dizilişi, dilbilgisi (Türkçe anlatım)
- **Tercüman:** Felemenkçe dinle → Türkçe anlam + cevap önerileri; Türkçe söyle → Felemenkçe (okunuş + ses)
- **Pratik:** gerçek hayat görevleri ve konuşma senaryoları
- **Yardım:** mektup/bordro fotoğrafı açıklama, mesaj yazma, telefon hazırlığı, "İlk 12 ay" listesi

Hazır dersler internetsiz ve anahtarsız çalışır. Yapay zekâ özellikleri kullanıcının kendi Claude API anahtarıyla, doğrudan tarayıcıdan çalışır; anahtar yalnız o cihazda saklanır, bu depoda hiçbir anahtar yoktur. Ses kaydedilmez.

Belçika'daki resmî bilgiler genel rehberdir; güncel kuralı her zaman ilgili kurumdan kontrol edin.
